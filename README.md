## Prérequis

Pour exécuter ce projet il faut avoir installé:
1. **Python 3.x**
2. **Java (JRE/JDK)** : Nécessaire pour faire tourner le processeur Saxon.
3. Vérifiez que l'exécutable **`saxon-he-10.3.jar`** est bien présent à la racine du projet, à côté du fichier `main.py`.

## Lancer la génération

1. Ouvrez un terminal et se placer dans le dossier du projet.
2. Lancez le script Python avec la commande suivante :
   ```bash
   python3 main.py
